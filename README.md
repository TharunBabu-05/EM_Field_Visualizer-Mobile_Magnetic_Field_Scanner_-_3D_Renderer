# EM Field Visualizer - Android Project

This is an advanced Android application for visualizing electromagnetic fields in 3D space.

## Setup Instructions

1. Open this project in Android Studio
2. Sync Gradle files
3. Build and run on a physical device (magnetometer required)

## Requirements
- Android Studio Arctic Fox or later
- Android SDK 34
- NDK 25.1+
- Physical device with magnetometer, accelerometer, and gyroscope

## Project Structure
- `app/src/main/java` - Kotlin source code
- `app/src/main/cpp` - Native C++ code for performance
- `app/src/main/res` - Android resources (layouts, strings, etc.)
